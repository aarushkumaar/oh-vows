🚀 Getting Started

1. Install Dependencies

cd card 3 npm install

2. Start Development Server

npm run dev

Opens at http://localhost:5173

3. Edit Content

  • Click ⚙ admin button (bottom right)
  • Select tab: General, Couple, Hero, Events, RSVP, Location
  • Make changes and click Save Changes

4. Build for Production

npm run build npm run preview

5. Deploy

# Vercel (recommended) vercel --prod # Or Netlify netlify deploy --prod --dir=dist

🎬 Key Features

Mobile-First Experience

Primary design for phones (320px+). Desktop is a refined adaptation, not the primary focus. The invitation feels like holding a physical card in your hand.

Interactive Event Stamps

Each event is a postage-stamp-style card that flips on tap/hover to reveal details. 3D rotation animation with perforated edges.

Editable Content Architecture

All content in src/data/config.ts. No code changes needed—admin panel handles everything.

Dynamic Event System

Add, remove, or reorder events. Support unlimited events with automatic layout adaptation.

Route Variants

One codebase, multiple invitation types. Different guests see different events based on URL.

Production-Ready

TypeScript for safety, Vite for speed, optimized animations, accessibility built-in.

🌹 Project Philosophy

GUL was designed to make digital wedding invitations feel authentic and warm—like a real invitation has come alive. Every interaction is purposeful, every animation is meaningful, and every detail honors the beauty of traditional Indian wedding aesthetics while embracing modern web technology.

The system is built to be extensible: add new event types, support multiple language, integrate with a backend for RSVP tracking—the architecture supports it all without modification to core components.
