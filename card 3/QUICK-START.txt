GUL — QUICK START GUIDE
========================

PROJECT STATUS: ✅ PRODUCTION READY

INSTALLATION
============
cd card\ 3
npm install

DEVELOPMENT
===========
npm run dev
→ Opens http://localhost:5173

EDIT CONTENT
============
1. Click ⚙ button (bottom right)
2. Select tab: General, Couple, Hero, Events, RSVP, Location
3. Make changes
4. Click "Save Changes"

BUILD FOR PRODUCTION
====================
npm run build
npm run preview

DEPLOY
======
Vercel (recommended):
  vercel --prod

Netlify:
  netlify deploy --prod --dir=dist

ROUTE VARIANTS
==============
?route=/all         → All events
?route=/bride/2     → Bride variant  
?route=/groom/T     → Groom variant

PROJECT STRUCTURE
=================

CONFIGURATION
=============
Edit src/data/config.ts to:
- Change couple names
- Update event details
- Modify RSVP settings
- Adjust location info
- Change theme colors
