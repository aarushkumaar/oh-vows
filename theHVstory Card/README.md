# Vartika & Hardik — Wedding Invitation Website

An interactive, illustrated, and editorial luxury wedding invitation for **Vartika & Hardik**.

## 🌺 Project Architecture

```
├── index.html                  # Semantic, accessible HTML5 structure
├── css/
│   ├── main.css               # Design system, typography, components & layout
│   ├── responsive.css         # Breakpoints, mobile hero & 2-col frame gallery
│   └── animations.css         # Keyframes & motion preferences
├── js/
│   ├── main.js                # App lifecycle, preloader & boot orchestration
│   ├── animations.js          # GSAP ScrollTrigger, floating drift & petals
│   ├── events.js              # Event data, dollhouse cards & modal routing
│   └── countdown.js           # Flip countdown timer
└── assets/
    └── images/
        ├── hero/              # Opening scene & couple illustration
        ├── backgrounds/       # Lehenga & ambient fabric textures
        ├── decorative/        # Garlands, lanterns & falling petals
        ├── frames/            # Frames of Forever (5 curated frames)
        ├── gallery/           # Polaroid memories on rope
        └── events/            # 5 Grand event invitations (PNG artwork)
```

## ✨ Highlights & Features

1. **Cinematic Hero Opening:**
   - Dominates the initial viewport with zoomed palace architecture and couple illustration.
   - Hanging architectural lanterns and marigold garlands frame the scene.
2. **Frames of Forever:**
   - 5 curated frames.
   - Responsive 2-column mobile gallery with centered 5th frame.
   - Gentle floating physics and scroll entrance.
3. **Polaroid Memories:**
   - Real photographic memories hanging from a golden rope with natural scroll drift.
4. **Our Grand Events:**
   - Transparent PNG invitations in a 3 + 2 layout on desktop, 2-col on tablet, 1-col on mobile.
   - Full-screen event detail view with "View Route" Google Maps navigation.
5. **RSVP & Family Invitation:**
   - Prominent focal point for Chhabra family attribution.
6. **Wardrobe Planner & Good to Know:**
   - Style guides for Sagan, Haldi, and Wedding.
7. **The Big Day Countdown:**
   - Real-time animated flip timer leading to 21 September 2026.

## 🚀 Static Hosting & Deployment

The codebase is fully static and repository-local with zero external file system dependencies. It deploys seamlessly to GitHub Pages, Netlify, Vercel, or any static web server.
